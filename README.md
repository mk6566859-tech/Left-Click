## 🚀 Key Functional Features & Micro-UIs
1. **Floating Island Navbar:** Morphing glass pill that shifts from transparent to frosted background on scroll.
2. **Opening Shot Hero:** Staggered GSAP timeline entrance with high-contrast typography and live telemetry ticker.
3. **Interactive Functional Artifacts:**
   - **Diagnostic Shuffler:** 3-second vertical card cycling using spring bounce transitions.
   - **Telemetry Typewriter:** Real-time monospace buying signal feed typing character-by-character.
   - **Cursor Protocol Scheduler:** Simulated animated mouse trajectory with interactive day scheduling.
4. **The Manifesto:** Paradigm contrast matrix comparing legacy spray-and-pray against sovereign outbound engines.
5. **Sticky Stacking Archive:** 3 full-screen pinned scroll cards with custom animated SVG visualizers (Concentric Radar Reticle, Scanning Laser Dot Matrix, and Pulsing EKG Waveform).
6. **Engagement Tiers & Guarantee:** 3 transparent pricing tiers with popping middle card and a 60-day performance threshold guarantee.
7. **Growth Consultation Modal:** Interactive 30-minute booking drawer with slot selection and qualification intake.
8. **Control Terminal Footer:** System operational status beacon and protocol navigation.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/mk6566859-tech/Left-Click.git
cd Left-Click

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to Vercel

The easiest way to deploy this Vite application is via [Vercel](https://vercel.com/):

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fmk6566859-tech%2FLeft-Click)

1. Connect your GitHub account to Vercel.
2. Import the `Left-Click` repository.
3. Vercel automatically detects **Vite** framework settings:
   - **Build Command:** `vite build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
4. Click **Deploy**.
